# Worked example: a timed PM take-home

The first session logged with this format. The exercise was to diagnose checkout abandonment at the payment step plus rising order cancellations on a B2B marketplace, and to write a short product brief and an honest note on how AI was used. Budget was 1–2 hours. Andrew worked with Claude Code.

| File | What it is |
|---|---|
| [`session_log.md`](session_log.md) | The full record: 43-row timeline, 15 verbatim prompts, 7 course-corrections, attribution, time |
| [`retrospective.md`](retrospective.md) | The one-page "how I used AI" note from the final deliverable |

**Read the retrospective first,** then the log's course-corrections if you want the detail behind it.

The headline numbers are in the [main README](../README.md#what-it-found-the-first-time). The log's main finding was that a template would fix most of the time lost to format. This repo is that template.

## What was sanitized

The company, the exercise text and platform-specific claims are removed or generalized. Redactions in the verbatim prompts are marked with [square brackets]. The exercise PDF, the brief and the working notes aren't included. Tag and layer names have been updated to the repo's scheme. The retrospective originally said the AI wrote "done" before checking twice; the log records it once, so the retrospective now says once. Nothing else was changed.
